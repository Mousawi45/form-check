# Form Check Live

Live rep counting and form checks from your phone camera, for the Daily Vitals gym tracker.

- Pose tracking runs on the phone (YOLO11n-pose via TensorFlow.js, WebGL). Video never leaves the device.
- Each exercise is judged against its own standard (depth, lockout, range of motion, tempo, drift, swing).
- At the end of a set, copy the result code and paste it into Daily Vitals → Gym to save it with the set.

Open it in Safari or Chrome and add it to your home screen.
